# 커뮤니티 디스코드 봇

Python `discord.py` 기반의 한국어 커뮤니티 관리 봇입니다. 서버 설정, 인증 상태, 레벨/출석 데이터, 통계 채널 및 운영 로그는 SQLite에 저장되며 재시작 후에도 유지됩니다.

## 주요 기능

- **버튼 CAPTCHA 인증**: 인증 패널 버튼을 누르면 왜곡된 이미지와 입력 모달을 Discord 안에서 표시합니다. HTTPS, 도메인, OAuth 로그인 없이 작동하며 인증 답은 해시로 저장하고 만료·재시도 제한·요청 쿨다운을 적용합니다.
- 이름·프로필 링크, 멘션, Discord 상대 시각을 포함한 환영/퇴장 안내와 메시지 수정/삭제, 음성 입퇴장·이동, 닉네임 변경 및 역할 생성/삭제 로그
- 최대 5개 역할을 선택/해제하는 셀프 역할 패널
- 로비 입장 시 임시 음성방 생성, 방장 이름/인원 제한/잠금/초대/추방 기능, 빈 방 주기적 정리
- 전체·온라인·인증 완료 인원 통계 음성 채널
- 채팅 및 음성 활동 XP, 레벨 보상 역할, 프로필 카드 이미지, TOP 10 랭킹, 일일 출석 및 7일 연속 보상
- 저장된 금지어/초대 링크 삭제, 메시지 도배 삭제 및 타임아웃
- 임베드 공지, DM 수신 동의자 대상 관리자 공지
- 검색 기반 음악 재생 및 버튼 제어, 한국어 TTS와 자동 음성 낭독
- 회전되는 `discord_bot.log` 파일 로그

활동 상태만으로 셀프봇을 신뢰성 있게 판별할 수 없으므로 셀프봇 자동 추방은 포함하지 않았습니다.

## 설치 및 실행

1. Python 3.10 이상을 설치합니다.
2. 프로젝트 폴더에서 가상환경을 만들고 의존성을 설치합니다.

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   py -m pip install -r requirements.txt
   ```

3. `.env.example`을 `.env`로 복사하고 `DISCORD_BOT_TOKEN`을 입력합니다. 이전에 노출된 토큰은 Developer Portal에서 폐기하고 새 토큰을 발급하세요. 토큰을 소스 코드에 넣거나 공유하지 마세요.
4. Discord Developer Portal의 **Bot → Privileged Gateway Intents**에서 **Server Members Intent**, **Message Content Intent**, **Presence Intent**를 활성화합니다.
5. 봇 초대 시 필요한 권한을 부여합니다: 채널 보기/메시지 보내기/임베드 링크/메시지 관리/역할 관리/채널 관리/멤버 타임아웃/음성 연결/말하기/메시지 기록 읽기. 봇의 최상위 역할을 인증·레벨·셀프 역할 지급 대상 역할보다 위에 둡니다.
6. 음악 및 TTS 음성 기능은 FFmpeg 실행 파일을 설치하고 PATH에서 `ffmpeg`를 실행할 수 있게 해야 합니다. 프로필 카드의 한글 글꼴이 필요하면 `.env`의 선택 설정 `BOT_FONT_PATH`에 사용할 글꼴 파일 경로를 지정합니다.
   Linux VPS에서는 Noto CJK 글꼴을 설치하세요 (Debian/Ubuntu: `sudo apt install fonts-noto-cjk`). 다른 경로의 글꼴은 `BOT_FONT_PATH`에 지정할 수 있습니다.
7. 실행합니다.

   ```powershell
   py bot.py
   ```

웹 대시보드는 제거되었습니다. 서버 설정과 관리는 Discord 슬래시 명령어를 사용하세요. 기존 SQLite의 서버 설정 및 자동 TTS 데이터는 그대로 유지됩니다.

슬래시 명령어는 봇 시작 시 전역으로 동기화되며 Discord에 반영되기까지 시간이 걸릴 수 있습니다. 명령은 서버에서만 사용 가능합니다. 관리자 설정 명령은 Discord에서 관리자에게만 표시되고 실행도 관리자 권한으로 제한됩니다. 일반 멤버용 명령은 서버 멤버가 사용할 수 있습니다. 봇을 여러 서버에서 쓰려면 Developer Portal에서 해당 설치 컨텍스트와 권한을 설정한 초대 링크로 각 서버에 추가하세요.

## GitHub에서 24시간 실행

GitHub는 코드를 저장하고 변경 사항을 배포 서비스로 전달하는 역할만 하므로, 봇을 계속 실행하려면 상시 실행 호스팅 서비스가 별도로 필요합니다. 이 프로젝트는 Render의 Docker 백그라운드 워커 배포 구성을 포함합니다. 24시간 실행은 유료 워커 요금제가 필요하며, 무료 서비스는 상시 실행을 보장하지 않습니다.

1. GitHub에 저장소를 만들고 프로젝트 파일을 올립니다. `.env`, `bot_data.sqlite3` 및 로그 파일은 올리지 마세요. 이 파일들은 `.gitignore`에서 제외됩니다.
2. Render에서 **New → Blueprint**를 선택하고 GitHub 계정을 연결한 다음 저장소를 선택합니다.
3. Blueprint가 `render.yaml`의 `community-discord-bot` 워커를 찾으면 배포를 진행합니다.
4. Render 서비스의 환경 변수에 `DISCORD_BOT_TOKEN`을 추가합니다. 토큰은 GitHub에 입력하거나 커밋하지 마세요.
5. 배포 로그에 봇의 Discord 로그인 및 준비 완료 메시지가 나타나는지 확인합니다. Developer Portal에서 필요한 Privileged Gateway Intents가 켜져 있어야 합니다.

SQLite 데이터베이스는 Render의 `/var/data` 영속 디스크에 저장되므로 컨테이너가 다시 배포되어도 유지됩니다. 단, 기존 PC의 서버 설정 데이터는 새 호스팅 환경으로 자동 복사되지 않습니다. 기존 데이터를 옮기려면 봇을 종료한 뒤 `bot_data.sqlite3` 파일을 별도로 안전하게 이전해야 합니다. 이 파일에는 서버 설정과 사용자 활동 데이터가 있으므로 GitHub에 올리지 마세요.

## 첫 설정

서버 관리자 권한이 있는 멤버가 다음 순서로 서버 기능을 설정할 수 있습니다.

1. `/로그채널지정`으로 운영 로그 채널 지정
2. `/보안인증서생성`으로 인증 채널과 지급할 역할을 지정하고 버튼 CAPTCHA 패널 게시. 모든 기존 카테고리와 안의 채널은 미인증 멤버에게 숨겨지고, 인증 채널만 공개됩니다. 인증 역할이 부여되면 카테고리를 볼 수 있습니다. 봇에 채널 관리 권한이 필요합니다.
3. `/역할지급패널생성`으로 셀프 역할 메뉴 게시
4. `/보이스입장채널지정`에 카테고리를 지정해 `음성채널 생성` 로비 생성. 멤버가 이 음성 채널에 들어가면 개인 게임방이 자동 생성됩니다.
5. `/통계채널설정`으로 통계 카테고리와 음성 채널 생성
6. `/환영퇴장채널지정`에 안내를 보낼 텍스트 채널을 지정합니다. 지정하지 않으면 로그 채널, 그 다음 서버 시스템 채널을 사용합니다.

## 명령어

### 관리자

아래 명령은 서버의 **관리자 권한**이 있는 멤버만 사용할 수 있습니다.

| 명령어 | 기능 |
| --- | --- |
| `/로그채널지정` | 서버 로그 채널 설정 |
| `/환영퇴장채널지정` | 환영/퇴장 안내 채널 설정 (생략하면 로그 채널로 초기화) |
| `/보안인증서생성` | 인증 역할을 설정하고 CAPTCHA 버튼 패널 게시 |
| `/역할지급패널생성` | 최대 5개 역할 셀프 선택 패널 게시 |
| `/보이스입장채널지정` | 선택한 카테고리에 `음성채널 생성` 로비를 만들거나 다시 설정 |
| `/통계채널설정` | 전체/온라인/인증 통계 음성 채널 생성 및 갱신 |
| `/출석보상역할설정` | 7일 연속 출석 보상 역할 설정 |
| `/고급공지작성` | 지정 채널에 임베드 공지 게시 |
| `/디엠공지전송` | DM 수신 동의자에게 공지 전송 |

### 멤버

| 명령어 | 기능 |
| --- | --- |
| `/레벨` | 레벨, 경험치, 서버 순위 프로필 카드 확인 |
| `/랭킹` | 서버 경험치 TOP 10 확인 |
| `/출석체크` | 하루 한 번 출석하고 랜덤 XP 지급 |
| `/공지수신` | `수신: True`로 DM 공지 동의, `False`로 언제든 해제 |
| `/방이름변경`, `/방인원제한`, `/방잠금` | 내가 만든 임시 음성방 관리 |
| `/방초대`, `/방추방` | 임시 음성방 멤버 초대/추방 |
| `/tts`, `/tts중지`, `/tts퇴장` | `/tts`를 한 번 실행하면 본인이 서버의 어느 텍스트 채널에 쓰더라도, 지정된 음성 채널에 있는 동안 메시지를 이름을 붙이지 않고 계속 읽습니다. `/tts중지` 또는 음성 채널 퇴장으로 종료 |
| `/음악재생`, `/음악볼륨`, `/음악나가기` | 음악 검색/재생, 볼륨(0~100%) 조절 및 종료 |

음악 재생 메시지의 **반복** 버튼을 누르면 현재 곡 반복 재생을 켜거나 끌 수 있습니다. 반복 중에도 건너뛰기를 누르면 다음 대기 곡으로 넘어갑니다. **재생 정지** 버튼은 곡과 대기열만 정지하고 봇을 음성 채널에 유지하며, 봇을 내보내려면 `/음악나가기`를 사용합니다. 음성 채널에 사람이 한 명도 남지 않으면 TTS와 음악을 정리하고 5초 후 봇이 자동으로 퇴장합니다.

채팅 XP는 60초마다 한 번 지급되고 음성 XP는 10분 주기로 지급됩니다. 일일 출석 보상과 레벨업 공식은 명령어 응답에 표시됩니다. DM 공지는 수신 동의한 모든 멤버에게 발송합니다. 인원 상한은 없으며, Discord DM 전송 제한을 고려해 초당 1회 및 30명마다 추가로 5초 대기합니다. 모든 명령어 응답은 서버 채널에 공개됩니다.

음악 제공자와 Discord의 서비스 약관 및 저작권을 준수하세요. 봇은 음악 스트림을 다운로드해 저장하지 않으며, 계정 쿠키나 접근 제한 우회 설정을 사용하지 않습니다. TTS 음성 생성은 Microsoft Edge TTS 서비스에 텍스트를 전송할 수 있으므로 민감한 정보를 입력하지 마세요.

## 봇 이름과 프로필 이미지

봇의 실제 표시 이름을 **꼬꼬마**로 바꾸고 제공된 아바타 이미지를 적용하려면 Discord Developer Portal에서 애플리케이션의 **Bot** 설정으로 이동해 username과 avatar를 직접 변경하세요. 코드의 활동 상태 문구는 실제 봇 username/avatar를 변경하지 않습니다.

## VPS에서 PM2로 실행 (선택)

Linux 서버에 Python, FFmpeg, Node.js를 설치하고 프로젝트 의존성을 설치한 후:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
sudo npm install --global pm2
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

프로세스 로그는 `pm2 logs community-discord-bot`으로 확인할 수 있습니다. `.env`, SQLite 데이터베이스, `discord_bot.log` 파일은 서버에서 백업하고 `.env`를 공개 저장소에 올리지 마세요. 웹 대시보드는 포함되어 있지 않습니다.
